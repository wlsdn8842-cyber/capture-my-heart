Public Beta Changelog

무엇이 바뀌었고, 왜 바꿨나요?

실제 플레이 피드백과 세션 데이터를 보고 조정한 내용을 기록합니다. 새 기능만 적는 것이 아니라, 테스트 결과 문제가 생겨 되돌린 변경도 함께 공개합니다.

v0.13.5 · Key Mapping

2026-10-06

메인 화면과 게임 내 설정을 ‘옵션’으로 통일하고, PC 키보드용 키맵핑을 추가했습니다. 이동 4방향, CAPTURE, DASH, 옵션 키를 변경할 수 있고 각 기능에 최대 두 개의 키를 지정할 수 있습니다. 중복 키와 일부 브라우저 예약키는 차단하며 기본값 복원 기능을 제공합니다. 튜토리얼과 도움말도 현재 키 설정을 따라 표시됩니다.

v0.13.4 · HUD Audio Controls

2026-10-05

게임 중 상단 HUD에서 BGM을 바로 켜고 끄고, 볼륨을 조절할 수 있도록 했습니다. BGM과 효과음 설정을 분리해 음악만 끄고 게임 효과음은 유지할 수 있습니다. 기존 일시정지 아이콘은 의미가 더 분명하도록 ‘옵션’ 텍스트로 바꿨습니다.

v0.13.3 · Mobile Rotation Recovery

2026-10-05

모바일에서 세로·가로 회전 후 브라우저 주소창과 visual viewport 크기가 늦게 갱신되면서 화면 비율이 깨지는 문제를 보완했습니다. 회전 직후 여러 시점에 뷰포트를 다시 측정하고 렌더 루프를 재시작해 가로 모드 복귀 안정성을 높였습니다.

Movement v2 실험 · 롤백

2026-10-05

점령 경계만 따라 이동하는 방식과 랜덤 스폰을 실험했습니다. 라인을 따라 움직이는 감각 자체는 긍정적이었지만, 보스 탈출과 영역 재구성이 겹칠 때 플레이어가 특정 경계에 갇히는 회귀가 반복되어 안정판 v0.13.3으로 되돌렸습니다. 이후 이동 시스템은 본편에 덧대는 방식이 아니라 별도 테스트 환경에서 충분히 검증한 뒤 다시 검토할 예정입니다.

v0.13.2 · Collection 3-Day Access

2026-10-05

Stage 10 완주 직후 컬렉션 요청 화면을 놓친 경우를 위해 같은 브라우저에서 72시간 동안 타이틀과 갤러리에서 MY COLLECTION을 다시 열 수 있도록 했습니다. 기간이 지나면 버튼은 자동으로 사라지고, 재완주하면 72시간이 다시 시작됩니다.

v0.13.1 · Collection Reliability

2026-10-05

컬렉션 요청이 서버에 도착한 뒤 500 오류로 실패하던 문제를 조사해 서버 전용 DB 권한 누락을 수정했습니다. 공개 사용자 권한은 열지 않고 service role에 필요한 최소 권한만 복구했으며, 이후 서버 오류와 네트워크 오류를 사용자에게 구분해 안내하도록 개선했습니다.

v0.13.0 · Difficulty v2

2026-10-05

초반 스테이지가 지나치게 쉬워 후반까지 긴장감이 이어지지 않는다는 의견을 반영해 전체 난이도 곡선을 상향했습니다. Stage 1부터 적탄과 졸개가 등장하며, 후반부는 속도·탄 빈도·추적 압박·보스 패턴 빈도를 더 강하게 조정했습니다. Stage 3의 레이저, Stage 5의 영역 파괴, Stage 8의 순간이동 구조는 유지했습니다.

Service Scene HQ

2026-10-05

Stage 1~10의 90% 보너스 장면을 새 영상으로 교체하고, 모바일과 데스크톱 모두에서 기존 재생·다시보기·정지 이미지 전환 동작을 유지했습니다. 초기 압축본에서 화질 저하가 크게 보여 고화질 MP4 자산으로 다시 교체했습니다.

업데이트 원칙

새 기능을 많이 넣는 것보다 실제 플레이 흐름이 깨지지 않는 것을 우선합니다. 큰 시스템 변경은 기준 버전을 브랜치로 보존하고, 빌드 검증과 회귀 테스트를 통과한 뒤 배포합니다. 그래도 실제 사용자 환경에서 문제가 발견되면 기능을 유지하기 위해 덧붙이기보다 안정판으로 되돌리는 선택을 할 수 있습니다.
